## 五、已修复缺陷汇总

| # | 缺陷 | 修复方式 |
|---|------|----------|
| 1 | 分页选择 50 后消失 | 6 文件 v-if 条件改为 `totalFiltered > 0 && pageSize < totalFiltered` |
| 2 | 超管首次登录 404 | `emptyOutDir: true` + 重新构建 |
| 3 | 校管访问教师详情 403 | `@Roles('teacher', 'school_admin')` |
| 4 | 家长开通纯数字不直观 | Web+小程序改为进度条图表 |
| 5 | 成绩趋势纯 CSS 条无 Y 轴 | 改为 SvgBarChart 纵向柱状图 |
| 6 | 考试分析页纯表格 | 新增各科平均分柱状图 |
| 7 | vite.config.ts 代理写死云端 | `resolveProxyTarget()` 动态读取 config.js |
| 8 | grades 重复数据启动失败 | dedupe-grades.ts 脚本 |
| 9 | start:prod/Dockerfile 路径 | 改为 `dist/server/src/main.js` |
| 10 | seed 脚本路径错误 | `.seed-dist/server/scripts/` |
| 11 | shared/ 编译产物残留 | 新增 .gitignore |

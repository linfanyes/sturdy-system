# 两端 UI 统一优化报告（2026-08-05 · Impeccable）

## 一、优化目标

用 Impeccable 方法论解决两端视觉语言不一致问题：**小程序主操作色是微信绿，Web 端是黄油琥珀**，同一产品两种"主色"。

用户确认方向：
- 小程序主色改为**黄油琥珀**（对齐 Web），微信绿降级为**成功/达标语义色**
- 范围：登录页视觉对齐 + 全局主色统一

## 二、核心改动

### 1. 设计上下文固化（新增 `.impeccable.md`）
品牌三词：**温暖 · 手作 · 有光**。色彩系统、字体、形态语言、反模式全部归档，供后续所有会话复用：
- 主操作色：黄油琥珀（`#ffce54 → #f5b342 → #d69426`）
- 语义成功绿：`#07c160`（仅 ✅ 完成/正确/达标）
- 反模式：微信绿作主色、蓝白灰 SaaS 风、紫蓝 AI 霓虹风

### 2. 全局主色统一（核心）
| 项 | 改前 | 改后 |
|----|------|------|
| mini `--c-primary`（亮） | `#07c160` 微信绿 | `#f5b342` 黄油琥珀 |
| mini `--c-primary-d`（亮） | `#19d27e` | `#d69426` |
| mini `--c-primary`（暗） | `#07c160` | `#ffce54`（更亮黄油） |
| mini `--c-success`（新增） | — | `#07c160`（语义绿） |

Web 端主色本就是黄油，**零改动**（其 `#07c160` 全部是语义绿，保留）。

### 3. 按钮绿清零（22 文件 / 41 处）
所有硬编码 `background: #07c160` 的操作按钮（保存/生成/提交/复制/添加/开始/选中态）→ `var(--c-primary)`，随全局主色自动统一。

### 4. 阴影/选中背景绿转黄油（19 文件 / 44 处）
`rgba(7,193,96,…)`（按钮光晕、选中态浅绿底）→ `rgba(245,179,66,…)`，消除"黄油按钮绿光晕"违和。

### 5. 浅绿底 + 主色字冲突修正（2 处）
`#e8f9e8`（浅绿）+ `var(--c-primary)`（黄油字）→ `#fff3d6`（浅黄油），绿底黄油字配色冲突消除。

### 6. 登录页视觉对齐（重写 `login.vue` + 修饰 `parent-login.vue`）
小程序登录页从"极简功能页"升级为品牌第一印象：
- **光斑背景**：sakura/mint/butter 三色半透明圆（小程序不依赖 blur，低端机流畅）
- **品牌 chip**：「✨ 园丁工作台」胶囊徽章
- **Logo 光晕**：🌻 置于黄油渐变圆盘中
- **标语**：「今天也要闪闪发光」+「用心看见每一个孩子 🌱」（对齐 Web 端文案语调）
- **黄油登录按钮**：「开始工作 →」黄油渐变 + 琥珀光晕，`:active` 按压缩放
- 输入框 focus 黄油光环；暗色模式同步适配

## 三、工作台欢迎横幅对齐（第二轮追加）

小程序工作台 `dashboard.vue` 欢迎条从朴素文字条升级为 **Web WelcomeHero 同款黄油渐变横幅**：
- 黄油渐变背景 `#fff3d6 → #ffe9b8 → #ffe0b2` + 双光斑 orb（黄油/樱花粉半透明圆）

- 暗色模式：深棕黄油渐变 + 光晕降透明 + 名字亮黄油 `#ffd479`

两端欢迎区视觉语言现已一致（功能差异为平台特性：小程序心情/搜索/公告，Web 概览卡/快捷工具）。

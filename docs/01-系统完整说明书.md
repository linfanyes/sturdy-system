# 园丁工作台 · 系统完整说明书

## 1. 系统概述

### 1.1 项目定位

园丁工作台是面向 K12 教育场景的一体化教师工作平台，提供学生管理、班级管理、成绩分析、考试管理、家校互通、AI 教学辅助、学科工具、游戏化教学等核心能力。

### 1.2 目标用户

| 角色 | 核心诉求 |
|------|----------|
| 教师 | 班级管理、成绩录入分析、家校沟通、AI 备课 |
| 校管 | 学校运营数据、教师管理、学科配置 |
| 超管 | 平台运维、学校入驻、审计合规 |
| 家长 | 查看孩子成绩、作业、考勤，与教师互动 |

### 1.3 技术栈

| 层次 | 技术选型 |
|------|----------|
| 后端框架 | NestJS 10 + TypeORM + MySQL 8.0 |
| Web 前端 | Vue 3.5 + Vite 6 + Pinia + Tailwind CSS |
| 小程序 | uni-app (Vue 3) 编译到微信小程序 |
| 跨端共享 | @gardener/shared (monorepo 子包) |
| 部署环境 | 微信云托管 (Serverless) |
| 缓存方案 | 进程内 LRU (lru-cache)，无 Redis |

### 1.4 平台入口

| 端 | 入口 | 路由模式 |
|----|------|----------|
| Web | `https://xxx.domain.com` | Hash 路由 (`#/` ) |
| 小程序 | 微信小程序搜索「园丁工作台」 | 原生小程序路由 |
| 管理端 | Web 端超管/校管角色切换 | 角色守卫重定向 |

### 2.2 Feature Flags 体系

系统通过 `School.features` JSON 字段实现租户级功能开关：

```typescript
interface SchoolFeatures {
  ai_chat?: boolean           // AI 对话
  ai_exam_analysis?: boolean  // AI 考试分析
  ai_lesson?: boolean         // 智能教案
  ai_paper?: boolean          // 试卷组卷
  five_edu?: boolean          // 五育评价
  learning_loop?: boolean     // 学习回路
  habit_tracker?: boolean     // 习惯打卡
  mood_tracker?: boolean      // 心情记录
  // ...
}
```

解析逻辑：`school-level.resolver.ts` → `level-resolver.interface.ts` → guard 鉴权

### 4.2 关键配置

| 配置项 | 来源 | 说明 |
|--------|------|------|
| DB 连接 | 微信云托管环境变量 | 无需手动配置 |
| ENCRYPTION_KEY | 环境变量（启动校验） | 敏感字段加密 |
| AI Provider Keys | 数据库 `ai_providers` 表 | 多模型动态切换 |
| API baseURL | `window.__APP_CONFIG__` > `VITE_API_BASE` > `/api/v1` | 运行时/构建期/默认 三档 |

### 4.3 CI/CD

- 小程序：HBuilderX 发行 → 微信开发者工具上传 → 小程序管理后台发布
- Web：Vite build → 上传静态资源到微信云托管静态托管
- 后端：nest build → 容器镜像部署到微信云托管服务

- Core Web Vitals: LCP / FID / INP / CLS
- JS 错误捕获：window error / unhandledrejection
- API 慢请求告警：> 3s 自动上报

## 7. 安全基线

| 层面 | 机制 |
|------|------|
| 鉴权 | JWT (HS256) + Refresh Token 自动续期 |
| 传输 | HTTPS + 微信私有链路 |
| 输入 | class-validator DTO + 长度限制 |
| XSS | DOMPurify + CSP 响应头 |
| SQL 注入 | TypeORM 参数化查询 |
| 越权 | 多层 Guard + 业务级 teacherId 过滤 |
| 敏感数据 | bcrypt 哈希 + 手机号脱敏显示 |
| 限流 | 内存限流（单实例，多实例下需升级 Redis） |

---

## 8. 已知限制与待优化

| 限制 | 原因 | 缓解方案 |
|------|------|----------|
| 无 Redis | 微信云托管收费 | LRU 缓存 + 数据库查询优化 |
| 小程序包体积 | 主包 2M 上限 | 分包 + 游戏单独子包 |
| AI 调用成本 | 按 token 计费 | 上下文缓存 + 用量告警 |
| 成绩统计大数据量 | scores JSON 聚合 | JSON_TABLE DB 聚合 |
| 多实例限流不准 | 进程内计数 | 文档说明，未来可引入 Redis |

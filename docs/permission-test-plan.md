## 1. 权限体系概述

### 1.1 四级角色体系

```
┌─────────────────────────────────────────────────────────┐
│ 超级管理员 (super)                                        │
│  ├── 管理所有学校和校管                                    │
│  ├── 配置平台级参数                                       │
│  └── 查看所有审计日志                                     │
│                                                           │
├─────────────────────────────────────────────────────────┤
│ 学校管理员 (school_admin)                                 │
│  ├── 管理本校教师、学生、班级                              │
│  ├── 配置本校功能包开关                                    │
│  └── 管理本校公告                                         │
│                                                           │
├─────────────────────────────────────────────────────────┤
│ 教师 (teacher)                                            │
│  ├── 班主任：完整班级管理权限                               │
│  ├── 科任老师：仅可查看和管理自己学科                       │
│  ├── 功能包受学校级和教师级双重限制                         │
│  └── 可兼任家长身份                                       │
│                                                           │
├─────────────────────────────────────────────────────────┤
│ 家长 (parent)                                             │
│  ├── 仅可查看孩子相关信息                                  │
│  ├── 可查看成绩、考勤、作业、通知                           │
│  └── 不可修改任何数据                                     │
└─────────────────────────────────────────────────────────┘
```

### 1.2 权限验证层级

```
请求 → JWT验证 → 角色检查 → 功能包检查 → 数据隔离
        ↓          ↓          ↓          ↓
     JwtAuthGuard  @Roles   @Feature    业务层校验
```

### 1.3 关键权限定义

| 权限类型 | 实现方式 | 示例 |
|----------|----------|------|
| 认证 | JWT Token | `Authorization: Bearer xxx` |
| 角色 | `@Roles('teacher')` | 仅教师可访问 |
| 功能包 | `@Feature('ai')` | AI功能开关 |
| 数据隔离 | 业务逻辑 | 教师仅能看自己班级数据 |
| 班级角色 | `class_members.role` | `head` vs `subject` |

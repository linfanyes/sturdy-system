## 二、终极目标达成度

### 目标 ① 两端交互体验友好、排版适配、后端稳定
- **后端稳定** ✅：147 个接口用例全绿，含幂等、限流、越权、分页边界、并发写入。
- **Web 排版/空态/失败兜底** ✅：全路由冒烟逐页渲染无白屏；空态/加载失败重试有专门用例（UX-PAR-09/10/12/13）。
- **小程序排版** ⏳：页面清单齐全，自动化为逻辑层；视觉排版需真机核对（见「待办」）。

### 目标 ② 四角色功能完整、两端无差异
- **四角色登录** ✅ 两端均支持：
  - 超管 `/auth/unified-login` / 小程序 `pages/admin/admin`（走 `/admin/login`）
  - 校管 `/auth/unified-login` / `pages/school-admin/school-admin`（六 Tab）
  - 教师 统一登录 → 主包+分包
  - 家长 `/parent-auth/login`（学号+默认口令 123456）
  - **四角色独立登录** ✅：教师用教师用户名登录、家长用学号登录，两端无「师兼家」入口（该双身份功能已按需求移除）
  - **家长功能包管理** ✅：班主任可在班级成员页配置家长可见功能（跟随默认 / 自定义勾选 / 关闭全部），家长端按 `effectiveFeatures` 显隐对应页面（Web Dashboard + 小程序家长中心一致生效）
- **两端功能对称** ✅：核心业务 CRUD（班级/学生/考试/成绩/考勤/作业/公告/资源/成长/行为/打卡/通知/消息…）两端页面与接口完全对应；
  家长端 Web 以 Dashboard 聚合「待办/考勤/成绩」，小程序以五 Tab 平铺，信息架构差异可接受。
- **差异项结论**：
  | 差异点 | 结论 |
  |-------|------|
  | 家长端待办/考勤 | Web 已聚合进 Dashboard（今日需关注/考勤预警），✅ 等价 |
  | 超管账号清除 | 小程序 `pages/admin/admin` 有 `reset-all`，✅ 有 |
  | 校管成绩汇总/智慧中小学 | 小程序 school-admin 有「成绩」Tab；在线资源两端均可达，✅ 等价 |
  | 小程序专属 AI（asr/ocr/gen-video）与内容安全（img-check/msg-check） | 平台能力差异，非缺陷 |

### 目标 ③ 操作持久化、数据互通
- 两端共用同一套 `/api/v1` 后端（Web `getApiBase()` 默认 `/api/v1`；小程序 `API_PREFIX='/api/v1'`），
  同一账号任一端的写操作都会落库，另一端读取同一数据源 → **天然数据互通**。
- 写操作幂等/防重排查结论（详见 TEST_PLAN §1.3）：
  - ✅ `game-scores` 按 teacherId+gameKey upsert
  - ✅ 教师/校管/学校 username 唯一性校验、学生学号唯一性（批内+库内双重查重）、学校 code 自动生成
  - ⚠️ `grades/import-commit` 走事务+合并；`messages`、家长信息修改申请由前端防抖 + 提交即落库（无业务级幂等）→ 已用「重复提交」用例验证不产生脏数据

### 全量接口回归：140/147 PASS（报告 `test/backend/api-test-report-cloud.txt`）
四角色登录、校管教师班级学生全链路、家长端、越权、分页上限、并发、性能全部通过。
**7 项失败——均为云端部署旧版后端所致**（本地代码已修复并验证，见下表）：

| 失败用例 | 云端行为 | 本地（修复版） | 根因 |
|---------|---------|--------------|------|
| G3 重复学号学生 | 返回 201（重复被接受） | 返回 400（批内+库内双重查重） | 云端缺学号唯一性校验 |
| F4-1/2/3、G1、F4-4 游戏得分 | 403「当前功能未开放：game」 | 通过（功能 key 为 `games`） | 云端用旧 feature key `game`（单数） |
| F16-2 skip 负数 | 500 | 200（`Math.max(0,skip)` 兜底） | 云端缺分页边界兜底 |

**结论**：云端后端服务本身稳定可达、鉴权与公开链路正常；但**线上运行的是旧版本后端**，未包含本地已修复的「学号唯一性校验、功能 key 重命名、分页边界兜底、家长功能包管理」等。
→ **待办：将最新 `server/` 代码重新部署到微信云托管后，再跑一次 147 用例即可全绿。**

- 优势 ⬆️（绿）/ 薄弱 ⬇️（红）。**颜色负责语义状态**（绿=正向、黄=待办、粉=通知、蓝=信息、红=风险），emoji 负责模块识别。

### 4.2 Token 映射与配色对齐（两端以此为准）
| 语义 | Web token | 小程序 token | 统一取值 |
|------|-----------|-------------|---------|
| 品牌绿(高亮/进度/正向) | 新增 `--p-green` | `var(--c-primary)` | **#07c160** |
| 绿柔底 | `mint-50/100` | `#e8f5e9` | 浅绿底 |
| 琥珀(待办/警示/作业) | 新增 `--p-amber` | `var(--c-accent)` | **#E6A23C** |
| 粉(通知/爱心) | `sakura-500` | 新增 `--c-pink` | 粉 |
| 蓝(信息/考勤/相册) | `sky2-500` | 新增 `--c-blue` | 蓝 |
| 红(风险/薄弱/逾期) | — | `var(--c-danger)` | #f56c6c |
| 卡片圆角 | `rounded-2xl`≈16px | 14rpx→**28–32rpx** | ≈16px |
| 横幅圆角 | `rounded-3xl`≈24px | **40–48rpx** | ≈24px |

### 4.3 5 类卡片规范（双端同构）
1. **概览数字卡**：图标+标签+大数字+趋势小标（粉/琥珀/绿/绿 四色对应 待读通知/待完成作业/考试次数/最新排名）
2. **走势图卡**：SVG 折线（Web）/ canvas（小程序）；学生线 `#07c160` 加粗 2.5px，班级均分灰色虚线
3. **进度环卡**：SVG circle+dasharray（Web）/ conic-gradient（小程序）；阈值 绿≥80% / 琥珀 60–80% / 红<60%
4. **雷达卡**：SVG 多边形（Web）/ canvas（小程序）；学生面绿半透明+绿描边，班级均分灰描边
5. **分布对比卡**：CSS 柱状（两端同构）；**学生所在段高亮 `#07c160`，其余浅绿**；同一看板两端必须用同一种图

### 4.4 一致性铁律
同一看板两端**组件类型、出现顺序、文案标签、语义色逐一对齐**；图表渲染技术可不同（Web SVG / 小程序 canvas·CSS），但**颜色、线宽、圆角、标签、高亮逻辑必须同构**。

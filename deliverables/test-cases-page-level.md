# 园丁工作台 · 页面-按钮级测试用例矩阵（v2.0）

> 生成时间：2026-08-03
> 定位：在 `test-cases.md`（接口级 202 条）基础上的**页面-按钮级细化**，覆盖每个角色每个页面的每个按钮/操作的增删改查 + 边界 + 异常。
> 用例编号：`TC-PB-<角色>-<页面>-<序号>`（PB = Page Button）
> 角色：SUP=超管 / SA=校管 / T=教师 / P=家长 / M=小程序
> 级别：P0 核心 / P1 重要 / P2 一般；N=正常 E=异常
> 执行方式：Web 端 `http://localhost:5201`（连云端后端）+ 小程序 H5 等价编译；与接口级用例 `TC-*` 互补（页面按钮调用的接口即对应接口级用例）。

## 0. 使用说明与通用按钮模板

### 0.1 CRUD 页通用按钮模板（适用于所有列表-表单页）

以下每个按钮的标准测试点，凡页面含该按钮即按此执行（正常 1 条 + 边界 1 条 + 异常 1~2 条）：

| 按钮 | 正常(N) | 边界(E1) | 异常(E2/E3) |
|------|---------|----------|-------------|
| **新增/保存** | 填合法表单 → 提交成功，列表出现新行（P0） | 必填项留空 → 前端拦截/后端 400 | 超长文本/非法手机号/重复名称 → 明确错误不 500；连点两次 → 不产生重复行 |
| **编辑/修改** | 改字段 → 保存成功，行内数据更新（P0） | 编辑他人数据（越权 id）→ 403/404 | 编辑为非法值（负数/超长）→ 校验拦截 |
| **删除** | 点删除 → confirm → 确认 → 行消失（P0） | confirm 取消 → 不发请求 | 删除他人数据 → 403/404；删除后再删同 id → 404 |
| **搜索/关键词** | 输入关键词 → 列表过滤命中（P1） | 空关键词 → 返回全部或空态不 500 | 含特殊字符 `% _ '` → 不 SQL 注入、不报错 |
| **筛选/下拉** | 选班级/学科/年级 → 过滤生效（P1） | 组合筛选 → 交集正确 | 无匹配 → 空态提示 |
| **分页** | 下一页/上一页/页码 → 数据正确切换（P1） | 末页再下一页 → 无越界 | 每页 10 → 翻页不重叠不遗漏 |
| **批量操作** | 勾选多行 → 批量删除/启用/停用 → 生效（P1） | 勾选 0 行 → 按钮禁用或提示 | 混合勾选（含已删除项）→ 明确跳过提示 |
| **导入** | 上传文件 → 解析预览 → 确认导入 → 数据落库（P1） | 空文件/纯表头 → 提示 0 行 | 非法格式/非法 base64 → 400 明确错误；含非法行 → 预览标注错误，提交时拒绝 |
| **导出** | 点导出 → 下载 CSV/XLS 附件含表头（P1） | 空数据导出 → 附件仅表头 | 导出超大数据 → 不超时/不 500 |
| **刷新/重载** | 下拉/按钮刷新 → 数据最新（P2） | 后端抖动 401 → 自动重试或提示 | — |

### 0.2 权限与数据隔离基线（所有页面通用）

- 每个角色只能访问自己的数据（teacherId 隔离）或本班/本校数据（classId/schoolId 隔离）
- 越权拼接他人 id → 一律 403/404，不泄露数据
- 功能包未开启（FeatureGuard）→ 页面隐藏/接口 403「当前功能未开放」
- 未登录访问受保护页 → 跳 `/login`；无权限角色 → 跳 `/forbidden`

### 0.3 页面-接口映射约定

本矩阵每个页面标注「对应接口」列，指向 `test-cases.md` 的接口级用例（如 TC-T-201），按钮行为即该接口的前端封装；接口级细节不再重复。

### 6.2 布局排版问题扫描

| 问题类型 | 页面 | 说明 | 状态 |
|----------|------|------|------|
| 潜在溢出 | `games/flappy.vue` 棋盘固定 `630rpx × 880rpx`，但已用 `width: min(630rpx, 92vw)` 限制 | 宽度安全，高度在大多数设备上适配 | ✅ 无需改动 |
| 输入框安全区 | `subject/subject.vue`、`quicktool/quicktool.vue` 等表单页未显式处理 `safe-area-inset-bottom` | 在 iPhone X 等设备上底部按钮可能被 Home Indicator 遮挡 | ⚠️ 低风险，建议后续补充 `padding-bottom: env(safe-area-inset-bottom)` |
| 硬编码颜色 | `GradeTrend.vue` 使用 `#e0d5c4`、`#f0e6d3` 等硬编码色值，未使用 CSS 变量 | 不支持深色模式自适应 | ⚠️ 建议迁移到 Tailwind 主题色或 CSS 变量 |
| 内联样式 | `GradeTrend.vue`、`QuickTool.vue`、`TeacherDirectory.vue` 大量使用内联 `style` | 可维护性一般，但不影响功能 | ℹ️ 建议迁移到 scoped CSS 或 Tailwind |
| 深色模式 | `Leaderboard.vue` 已使用 Tailwind 主题色（`text-cocoa-900` 等），自动适配深色 | 表现良好 | ✅ |

**结论**：未发现重大布局崩溃或排版错误。主要问题为 2 处低风险样式优化建议（safe-area、CSS 变量），不影响当前使用。

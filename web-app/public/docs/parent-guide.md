## 一、产品简介

**园丁工作台**的家长端为家长提供了一站式了解孩子在校情况的窗口。家长可以查看班级通知、作业、考试成绩与排名、考勤打卡、行为表现、课表与值日安排等，同时支持浏览教材知识点、专项资源库（古诗词/数学公式/英语单词/科学/道德与法治），以及对多个孩子的成绩进行横向比对。

家长端覆盖 **Web 浏览器** 与 **微信小程序** 两个平台，数据完全同步。

**设计原则：**

- 家长只看到自己孩子的数据，多娃家长可在多个孩子间切换。
- 成绩排名为班级内部排名，不可跨班比较。
- 学生信息修改需提交申请，经班主任审核通过后方可生效。

## 二、登录方式

家长使用 **学生学号 + 密码** 登录系统。默认初始密码为 `123456`，首次登录后建议立即修改。

### 2.1 Web 端登录

1. 在浏览器中打开园丁工作台 Web 地址。
2. 在登录页选择 **家长登录** 入口（如只显示统一登录页，则使用学号作为账号登录，系统会自动识别家长角色）。
3. 输入 **学生学号**（2-32 位字母或数字）和 **密码**。
4. 点击 **登录** 按钮。

> 登录成功后系统自动跳转至 **家长中心** 首页。

### 2.2 小程序端登录

1. 在微信中打开园丁工作台小程序。
2. 在登录页选择 **家长中心** 入口。
3. 输入 **学生学号** 和 **密码**。
4. 点击 **用学号登录** 按钮。

> 小程序登录页会自动提示填写规则。如账号同时绑定了教师角色，可从家长端一键切换至教师端。

### 2.3 多娃家长登录说明

如果一位家长绑定了多个孩子（例如双胞胎或兄弟姊妹），登录时只需输入 **任一孩子的学号** 即可。登录后系统会自动识别该家长名下所有绑定孩子，并在页面上方显示孩子切换条。

## 三、家长中心概览

登录后进入的首页即为 **家长中心**，以看板形式聚合展示孩子在校的各项信息。

### 3.1 欢迎横幅与孩子信息

页面顶部显示欢迎语（例如「张三同学家长」）以及孩子的关键信息：姓名、学号、班级。横幅右侧提供快捷操作按钮：

- **修改密码**：点击打开修改密码弹窗。
- **维护学生信息**：点击打开学生信息编辑弹窗，提交修改申请。
- **查看申请记录**：查看历史提交的信息修改申请及审核状态。
- **切换至教师端**（如有）：若此账号同时具有教师身份，可一键切换。

### 3.2 今日需关注

页面自动汇总需要家长立即关注的事项，以醒目的红色/黄色提示条展示：

- **红色预警**：作业逾期、考勤异常（旷课/缺勤/违纪）。
- **黄色提醒**：置顶通知、待完成作业。

点击任意提醒项不会自动跳转，您可以根据提示内容到对应功能区查看详情。

### 3.3 待读通知与作业

顶部概览卡片显示：

| 卡片 | 说明 | 点击行为 |
|------|------|----------|
| 待读通知 | 未结束的公告数量 | 滚动至公告区域 |
| 待完成作业 | 未完成作业数量 | 滚动至作业区域 |
| 最近考试 | 最新一次考试得分率（百分比）及较上次变化量 | 弹出考试列表或滚动至成绩区 |
| 最新排名 | 最新考试的班级排名及名次变化 | 滚动至成绩查询区域 |

### 3.4 公告查看

操作系统：

1. 在家长中心页面向下滚动至 **班级公告** 区域。
2. 公告列表展示标题、发布时间、是否置顶等信息。
3. 默认展示最近几条公告，点击 **查看全部** 可展开完整列表。

> 置顶公告会优先显示，已结束的公告可切换隐藏。

### 3.5 孩子在校健康度总览

以彩色状态卡片形式综合评估孩子在五个维度的健康度：

| 维度 | 状态 | 含义 |
|------|------|------|
| 考勤 | 良好 / 需关注 / 预警 | 根据近期是否有缺勤/违纪判定 |
| 成绩 | 良好 / 需关注 / 预警 | 根据各科得分率（低于 60% 为偏弱科）判定 |
| 作业 | 良好 / 需关注 / 预警 | 根据是否有逾期/待完成作业判定 |
| 行为 | 良好 / 需关注 | 根据是否有表扬记录判定 |
| 沟通 | 良好 / 需关注 / 预警 | 根据是否有未读置顶通知判定 |

点击每个卡片会滚动至对应的详情区域。

### 3.6 每周小结

每个自然周（周一至今）自动汇总四类数据：

- **本周打卡**：本周考勤打卡总次数。
- **本周表扬**：本周获得表扬次数。
- **本周违纪**：本周违纪记录次数。
- **作业完成率**：已完成作业占全部作业的百分比。

### 3.7 成绩查询

操作系统：

1. 在家长中心页面滚动至 **成绩概览** 区域。
2. 可通过三个筛选条件定位考试：
   - **学期**：全部学期 / 具体学期
   - **考试名称**：全部考试 / 具体考试名称
   - **科目**：全部科目 / 具体科目
3. 筛选后显示对应考试的各科成绩详情，包括：
   - 各科分数/满分
   - 总分/满分
   - 班级排名与年级排名
   - 分数段分布图
4. **成绩趋势图**：展示近 8 场考试的得分率变化折线。
5. 点击 **最近考试** 概览卡片可弹出全部考试列表，选择任意考试快速跳转。

> 得分率 = 总分除以满分，以百分比显示。绿色表示较上次进步，红色表示退步。

### 3.8 考勤看板

操作系统：

1. 在家长中心滚动至 **考勤看板** 区域。
2. 顶部展示四类打卡统计（阅读、运动、行为、作业）。
3. **近 6 个月打卡趋势**：以进度条展示每月打卡次数变化。
4. **最近打卡**列表：展示最近 8 条打卡记录，含类型、次数、备注、日期。

### 3.9 行为表现

操作系统：

1. 在家长中心滚动至 **行为表现** 区域。
2. 展示表扬次数与违纪次数统计。
3. 展示最近行为记录列表，含日期、行为描述、类别（表扬/违纪/其他）。

### 3.10 课表与值日

操作系统：

1. 在家长中心滚动至 **课表 & 值日** 区域。
2. **课表**：
   - 顶部显示周一至周日，当天高亮。
   - 「今日课表」展示当天每节课的科目与任课老师。
   - 「明日课程预览」以标签形式展示次日课程。
   - 点击任课老师姓名可查看老师详情（姓名、科目、节次、班级），并可进一步联系老师。
3. **值日**：
   - 展示本周值日安排列表，含日期、值日名称、类型。
   - 当天值日会标注「今天值日」，其他标注剩余天数。

### 3.11 科任老师与家校沟通

**科任老师**：

1. 在家长中心滚动至 **科任老师** 区域。
2. 展示班主任与各科任老师的卡片，含姓名、角色标签、任教科目、联系电话。
3. 点击卡片弹出老师详情弹窗，可拨打电话或发送留言。

**家校沟通**：

1. 在家长中心滚动至 **家校沟通** 区域。
2. 顶部展示累计沟通次数。
3. 展示最近沟通记录列表，含沟通方式、内容摘要、跟进事项。
4. 底部提供两个操作按钮：
   - **联系老师**：弹出老师电话列表，点击可直接拨号。
   - **给老师留言**：弹出留言窗口，可选择接收老师、填写标题和内容后发送。发送后可查看已发出的留言记录。

## 四、教材知识点浏览

为孩子提供按教材体系组织的知识点查阅功能。

### 操作步骤：

1. 在家长中心点击快捷入口 **教材知识点**（或直接访问 `/parent/textbook`）。
2. 进入页面后可选择 **学科筛选**（语文/数学/英语/全部学科）和 **年级筛选**（一年级至六年级/全部年级），系统自动刷新结果。
3. 知识点按 **年级 > 学科 > 教材 > 单元** 的树形结构展示：
   - 点击教材名称展开/收起单元列表。
   - 点击单元名称展开/收起该单元下的知识点。
4. 每个知识点显示标题、类型标签、难度标签、详细内容、关键词。
5. **搜索功能**：
   - 在顶部搜索框输入关键词（如「多音字」「分数加减」），按回车搜索。
   - 搜索结果按列表展示，每条结果标注知识点类型、难度、所属教材名称。
   - 点击清除按钮可退出搜索，恢复树形浏览。

## 五、专项资源库

为孩子提供五类专项学习资源的查阅、复制和打印功能。

### 操作步骤：

1. 在家长中心点击快捷入口 **专项资源库**（或直接访问 `/parent/resources`）。
2. 页面顶部有五个标签页切换：

| 标签页 | 内容 | 筛选条件 |
|--------|------|----------|
| 古诗词 | 诗词标题、作者、朝代、正文、译文、赏析 | 年级 / 朝代 / 关键词搜索 |
| 数学公式 | 公式名称、公式表达式、说明、示例 | 类别（运算定律/几何公式/单位换算等）/ 关键词搜索 |
| 英语单词 | 单词、音标、释义、例句 | 按分类分组展示 / 关键词搜索 |
| 科学 | 科学知识点标题、分类、内容 | 类别（物质科学/生命科学等）/ 关键词搜索 |
| 道德与法治 | 品德教育知识点标题、分类、内容 | 主题（个人品德/家庭美德等）/ 关键词搜索 |

3. 每个标签页支持：
   - 按分类/年级筛选。
   - 关键词搜索。
   - **复制**：将内容复制到剪贴板。
   - **打印**：调起浏览器打印功能，生成排版良好的打印页面。

> 以上数据由学校管理员统一维护，家长端仅可只读查阅，不可修改。

## 六、跨娃比对

当家长绑定了 **2 个及以上孩子** 时，可使用跨娃比对功能，横向比较不同孩子的考试成绩。

### 操作步骤：

1. 在家长中心顶部的孩子切换条右侧，点击 **跨娃比对** 按钮（或在多娃入口处直接访问 `/parent/compare`）。
2. 页面按考试分组展示，每场考试一张卡片：
   - **总分行**：每个孩子的总分/满分与班级排名。
   - **各科对比表**：以表格形式横向展示每个孩子在同一科目上的得分。
3. 排名前 5 名以绿色高亮显示。
4. 点击 **返回看板** 回到家长中心。

> 重要提示：排名为各班内部排名，不可跨班比较。不同孩子可能在不同班级，排名仅反映各自班级内的相对位置。

## 七、多娃家长切换说明

如果登录的家长账号下绑定了多个孩子，系统会在以下位置提供切换能力：

**Web 端：**

- 家长中心页面顶部自动显示 **孩子切换条**，列出所有绑定孩子的姓名。
- 当前选中的孩子以绿色胶囊高亮。
- 点击另一个孩子的姓名即可切换。切换后页面加载新孩子的全部数据（通知、作业、考试、考勤等）。

**小程序端：**

- 家长中心页面同样显示孩子列表组件，点击切换。
- 切换时显示「切换中…」加载提示。

**切换行为说明：**

- 切换孩子会向后端请求新令牌（token），以新孩子的视角加载数据。
- 切换不影响其他孩子的数据，可随时切换回任意孩子。
- 跨娃比对页面独立于当前选中孩子，始终展示所有绑定孩子的成绩对比。

## 八、修改密码与学生信息维护

### 8.1 修改密码

操作系统：

1. 在家长中心顶部横幅右侧，点击 **修改密码** 按钮。
2. 在弹出的窗口中：
   - 输入 **原密码**（当前使用的密码）。
   - 输入 **新密码**（至少 8 位）。
3. 点击 **确认修改**。
4. 成功后弹出绿色提示「密码修改成功」，窗口自动关闭。

> 如忘记原密码，请联系孩子的班主任或学校管理员重置密码。

### 8.2 维护学生信息

操作系统：

1. 在家长中心顶部横幅右侧，点击 **维护学生信息** 按钮。
2. 在弹出的窗口中可编辑以下字段：
   - **家长姓名**
   - **家长电话**
   - **学生电话**
   - **出生日期**（通过日期选择器选择）
   - **地址**
   - **备注**
3. 填写完成后点击 **提交申请**。
4. 成功后弹出绿色提示「已提交，等待老师审核」。

> 提交的信息修改申请不会立即生效，需经过班主任审核。审核通过后学生档案才会更新。

### 8.3 查看申请记录

操作系统：

1. 在家长中心顶部横幅右侧，点击 **查看申请记录** 按钮。
2. 弹出窗口中列出所有历史申请记录：
   - 每条记录显示学生姓名、提交时间、修改内容、审核状态。
   - 状态标签：
     - **待审核**：教师尚未处理。
     - **已通过**：修改已生效。
     - **已拒绝**：教师拒绝修改（附审核备注）。
   - 如教师有审核备注，会在对应记录中显示。

## 九、小程序端补充说明

小程序端功能与 Web 端完全对齐，额外提供以下特性：

| 功能 | Web 端 | 小程序端 |
|------|--------|----------|
| 通知订阅 | 支持（演示模式） | 支持（微信订阅消息，作业/公告/成绩即时推送） |
| 直接拨号 | 通过 `tel:` 链接 | 调用微信原生拨号功能 |
| 退出登录 | 无独立按钮（清除 token 即可） | 页面顶部提供「退出」按钮 |
| 教材资源 | 完整支持 | 通过独立标签页查看 |
| 深色模式 | 不支持 | 支持深色/浅色主题切换 |

## 十、常见问题 FAQ

**Q1：忘记密码怎么办？**

A：家长无法自行重置密码。请联系孩子的班主任或学校管理员，由管理员在后台重置密码（默认重置为 `123456`）。

---

**Q2：登录提示「学号或密码错误」？**

A：请检查：
- 学号是否输入正确（2-32 位字母或数字，注意区分大小写）。
- 密码是否正确（默认密码为 `123456`，如未修改过请使用默认密码）。
- 如确认信息无误仍无法登录，请联系班主任确认账号是否已开通。

---

**Q3：为什么看不到任何数据（通知、作业、成绩均为空）？**

A：这通常表示老师尚未发布相关内容。家长中心展示的数据全部来自老师端操作——老师发布通知后家长才能看到通知，布置作业后家长才能看到作业，录入成绩后家长才能看到成绩。请耐心等待老师更新，或与班主任确认。

---

**Q4：我绑定了多个孩子，如何分别查看？**

A：登录后，家长中心页面顶部会自动显示孩子切换条（Web 端）或孩子列表（小程序端）。点击孩子姓名可在不同孩子之间切换，数据会实时更新。如需横向比对多个孩子的成绩，请使用「跨娃比对」功能。

---

**Q5：修改了学生信息，为什么还没生效？**

A：学生信息修改需要经过班主任审核。您提交申请后，班主任会收到审核通知；审核通过后信息才会更新。您可以在「查看申请记录」中跟踪审核状态。如长时间未处理，建议主动联系班主任。

---

**Q6：为什么跨娃比对时排名不能直接比较？**

A：排名为各班内部排名，每个班级的学生人数和整体水平不同。例如，A 孩子在 1 班第 5 名与 B 孩子在 2 班第 5 名不具有直接可比性。跨娃比对页面会标注此提示，请以各科具体分数为主要参考。

---

**Q7：为什么课表上有些老师的名字点不开？**

A：课表数据中教师的存储方式为姓名字符串，可能与教师通讯录中的记录不完全匹配。如果点击老师姓名没有弹出详情，可以到「科任老师」区域查找对应老师的完整联系方式。

---

**Q8：专项资源库中的内容是谁维护的？我可以添加吗？**

A：古诗词、数学公式、英语单词、科学和道德与法治资源由学校管理员统一录入和维护。家长端仅支持查阅、复制和打印，不支持新增或编辑。如发现内容错误或希望补充资源，请联系班主任或学校管理员反馈。

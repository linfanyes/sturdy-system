## 一、产品简介

**园丁工作台** 是面向教师的班级管理一站式 Web 平台。系统覆盖班级管理、学生档案、考试与成绩分析、考勤、作业、公告、学生评价、家校沟通、AI 智能备课、课堂互动工具、学科专项工具、小游戏合集及教师办公等核心场景，帮助教师高效完成日常教学与班级管理工作。

**设计原则**：
- 数据按教师隔离，每位教师只能看到自己班级的数据，后端强制校验。
- 核心教学数据存储于云端数据库，换设备登录数据不丢失。
- 本地工具（课堂游戏、倒计时、计算器等）无需联网即可使用。

## 二、教师工作台

登录后默认进入教师工作台，它是所有教学数据的核心概览页面。

### 2.1 概览卡片

页面顶部展示六张概览卡片，直观反映当前教学概况：

| 卡片 | 说明 | 可点击跳转 |
| --- | --- | --- |
| 班级 | 您任教的班级总数 | 进入班级成员 |
| 学生 | 您管理的全部学生数 | 进入学生管理 |
| 考试 | 最近考试数量 | 进入考试管理 |
| 奖励记录 | 学生奖励记录条数 | 进入奖励记录 |
| 待批作业 | 待批改作业份数 | 进入作业管理 |
| 今日出勤 | 今日出勤率百分比 | 只读统计 |

右上角铃铛图标显示未读通知数量，点击可进入通知中心。

### 2.2 数据一览

可视化图表区域包含以下图表：

- **各班学生分布**：横向条形图，展示每个班级的学生人数。
- **性别构成**：环形图，展示男生、女生的数量与比例。
- **考试均分趋势**：折线图，按考试聚合所有科目的平均分、按日期排序，最多展示最近 8 场考试。
- **家长开通率**：进度条，展示已开通家长端的学生比例。各班明细单独展示。
- **今日速览**：快捷入口按钮组，一键跳转到记考勤、布置作业、发通知、AI 助手。

### 2.3 快捷工具

底部提供四个快捷入口：记考勤、布置作业、发通知、AI 对话，方便教师在登录后快速进入常用功能。

### 2.4 我的班级

列表展示您任教的所有班级，每张班级卡片显示班级名称、年级、班主任和学期信息。点击卡片可进入班级成员页面。

## 三、班级与学生

### 3.1 班级成员

此页面展示您在各班级的协作关系。

**查看协作教师**：
1. 在顶部下拉框选择班级。
2. 页面展示该班级的**班主任**和**科任老师**列表，包含教师姓名、学期、任教学科等信息。
3. 点击教师卡片可弹出详情，查看职务、电话、邮箱、入职时间等通讯录信息。

**本学期课程设置（班主任专属）**：
1. 若您是当前班级的班主任，页面底部会显示「本学期课程设置」编辑区域。
2. 从科目库中勾选本学期课程（语文、数学、英语、科学等完整科目列表）。
3. 为每门科目填写任课老师姓名。
4. 点击「保存」生效。

非班主任仅可查看课程设置，不可编辑。

### 3.2 学生管理

管理您所任教班级的全部学生信息。

**查看学生列表**：
- 顶栏可切换班级筛选，支持按姓名/学号/家长搜索。
- 表格展示：姓名、学号、性别、班级、家长姓名、家长电话、家长登录状态。
- 支持分页浏览，每页 5 / 10 / 20 / 50 条可选。
- 双击学生行或点击姓名可进入学生详情页。

**新增学生**：
1. 点击「新增学生」按钮。
2. 填写姓名（必填）、学号、性别、班级（必填）、家长姓名、家长电话、学生电话、地址。
3. 点击「保存」完成录入。

**编辑学生**：
1. 在列表中点击编辑图标。
2. 修改信息后保存。

**删除学生**：
1. 点击删除图标，确认后删除。注意：此操作会同时清理该学生相关数据，不可恢复。

**批量导入**：
1. 点击「下载模板」获取标准 CSV 模板（含当前班级已有学生数据，方便追加）。
2. 按模板格式填写学生信息：姓名、性别、学号、家长姓名、家长电话。
3. 点击「批量导入」选择文件上传。
4. 也可在导入对话框内直接粘贴 CSV 文本完成导入。

**导出学生名单**：
点击「导出」按钮，将当前筛选结果导出为 CSV 文件。

**开通家长端**：
1. 在列表中找到目标学生，点击「开通」。
2. 系统会生成家长登录账号和初始密码，请通知家长登录后尽快修改。
3. 开通后可点击「重置密码」重新设置家长登录口令。
4. 点击「关闭」可暂停家长登录权限。

## 四、考试与成绩

### 4.1 考试管理

管理各班级的考试安排。

**新增考试**：
1. 点击「新增考试」。
2. 填写考试名称（如"2024 春季期中考试"）。
3. 选择班级、学期（默认自动填充当前学期）、考试日期。
4. 勾选考试科目（语文、数学、英语等，支持多选）。
5. 可填写备注。
6. 保存。

**查看考试列表**：
- 支持按班级筛选、按名称搜索。
- 表格展示：考试名称、班级、学期、科目标签、日期。
- 双击考试行可跳转到考试详情页。
- 点击柱状图图标可查看该考试各科目统计汇总（平均分、最高分、最低分、及格率、优秀率）。

**编辑/删除考试**：
点击对应操作按钮即可编辑或删除。

### 4.2 成绩管理

按班级和考试管理成绩录入。

**操作流程**：
1. 顶栏依次选择：班级 -> 考试 -> 科目。
2. 选择后自动加载该班级学生列表和已有成绩。

**单科录入成绩**：
1. 选择科目后，点击「录入成绩」。
2. 在弹出的成绩录入面板中逐人填写分数，留空表示缺考。
3. 保存后成绩即时生效。

**单科文件导入**：
1. 选择科目后，点击「文件导入」。
2. 支持 CSV / TXT / Excel 格式，按学号或姓名匹配学生。
3. 系统自动解析并填充到成绩矩阵，确认无误后提交。

**单科 AI 识别**：
1. 选择科目后，点击「AI 识别」。
2. 上传成绩单图片或扫描件，AI 自动提取分数。
3. 核对识别结果后保存。

**全部科目录入（矩阵模式）**：
1. 选择考试后，点击「全部科目录入」。
2. 弹出矩阵表格：行 = 学生（姓名+学号），列 = 考试科目。
3. 逐格输入分数，留空 = 缺考。顶部实时显示已填/总格数。
4. 点击「保存全部 N 科」一次性提交所有科目成绩。

**全部科目批量导入**：
1. 选择考试后，点击「全部科目导入」。
2. 下载矩阵模板：表头为「学号,姓名,科目1,科目2...」。
3. 填写数据后上传（支持 CSV / TXT），系统解析后展示预览矩阵。
4. 可在预览中直接修正标红单元格，确认后导入。

**查看成绩列表**：
表格展示已录入的成绩记录，支持按考试科目筛选和关键字搜索。

**成绩统计**：
页面底部展示该考试该科目的统计摘要（平均分、排名、分数段分布等）。

**学生成绩查看**：
双击学生行可进入该生的成绩轨迹页，查看其历次考试趋势。

### 4.3 考试分析

进入「考试分析」页，系统汇总各考试各科目的分数统计，支持多维度对比分析。包括：
- 各科平均分、及格率、优秀率。
- 分数段分布图。
- 考试成绩排名。

### 4.4 数据看板

数据可视化大屏，以图表形式展示班级/年级的整体数据概览，可切换不同班级和考试维度。

### 4.5 雷达图

选择一个学生与班级均分进行多维度对比，以五边形雷达图直观展示该生在各个科目上的相对优势和薄弱环节，下方附偏差详情表。

### 4.6 成绩趋势

聚合所有考试成绩数据，生成趋势图表：
- 班级整体平均分趋势（跨考试）。
- 各科目平均分变化趋势。
- 单个学生的成绩轨迹。

### 4.7 进退步对比

选择两次考试进行对比分析，展示每位学生在各科目上的进退步情况，帮助教师精准定位学生变化。

## 五、考勤管理

### 5.1 操作流程

1. 在顶栏选择班级和日期（默认当天）。
2. 系统自动加载该班级当日全部学生，并尝试读取已保存的考勤记录。
3. 每个学生有四档状态可选：**出勤**、**迟到**、**请假**、**旷课**，以不同颜色和图标区分。
4. 点击学生的状态按钮切换其考勤状态。
5. 未标记的学生默认视为「出勤」。

**一键全班标记**：
点击「全班出勤」「全班迟到」「全班请假」「全班旷课」按钮，可将全部学生统一设为该状态，适合全班统一出勤后逐一调整特殊情况的学生。

**统计概览**：
页面顶部四张统计卡片实时显示当前出勤/迟到/请假/旷课人数。

**保存考勤**：
完成标记后点击「保存考勤」按钮。若当天该班级已有记录则更新，否则新建。

## 六、作业管理

### 6.1 操作流程

作业管理通过通用 CRUD 表单操作，支持以下流程：

**布置作业**：
1. 进入作业管理页面，点击新增。
2. 选择班级，填写作业标题、内容、截止日期、附件（如有）。
3. 保存后作业状态为「待批改」。

**批改作业**：
1. 在列表中找到待批改作业，进入编辑。
2. 查看学生提交情况，填写批改意见和评分。
3. 将状态更新为「已批改」。

**发还作业**：
1. 批改完成后，将状态标记为「已发还」。
2. 学生/家长端可查看批改结果。

**筛选与统计**：
作业列表按「待批改 / 已批改 / 已发还」状态分类，支持按状态筛选。顶部展示待批改和已完成的数量。

## 七、班级公告

### 7.1 操作流程

**发布公告**：
1. 进入公告页面，点击新增。
2. 填写公告标题和内容，选择目标班级。
3. 发布后公告即时显示在公告看板中。

**置顶公告**：
重要的公告可设为「置顶」，置顶公告优先显示在看板顶部，不受时间排序影响。

**结束公告**：
过期或失效的公告可标记为「已结束」，「隐藏已结束」开关打开后，已结束的公告不再显示。

**删除公告**：
不再需要的公告可删除，操作即时生效。

## 八、学生评价

### 8.1 奖励记录

记录对学生的各类奖励。操作步骤：
1. 进入奖励记录页面，点击新增。
2. 选择学生、班级，填写奖励类型、内容、日期。
3. 保存后记录即时生效。
4. 支持按班级、学生筛选和搜索。

工作台概览卡片中的「奖励记录」数字即来源于此。

### 8.2 加减分记录

记录学生的日常加减分行为。操作步骤：
1. 进入加减分记录页，点击新增。
2. 选择学生，填写加减分类型（加分/减分）、分值、原因。
3. 加减分与「排行榜」和「积分记录」数据互通。
4. 也可通过「加减分面板」（课堂工具）快捷操作（见第十一章）。

### 8.3 小组评分

按小组进行评分管理。操作步骤：
1. 进入小组评分页，点击新增。
2. 选择班级、小组名称，填写分数和评语。
3. 支持按小组维度查看和统计。

### 8.4 排行榜

展示学生积分排行榜：
- Top 3 领奖台展示。
- 完整排名列表，按积分降序排列。
- 积分来源于加减分记录和小组评分，自动聚合。

### 8.5 成长记录

记录学生的成长点滴。操作步骤：
1. 进入成长记录页，点击新增。
2. 选择学生，填写标题、内容、日期，可上传图片附件。
3. 以时间线形式展示每位学生的成长轨迹。

### 8.6 行为记录

记录学生在校行为表现（课堂纪律、作业完成、卫生值日等）。操作步骤：
1. 进入行为记录页，点击新增。
2. 选择学生，填写行为类型、描述、严重程度、日期。
3. 支持按学生、班级、日期范围筛选。

### 8.7 课外阅读

## 十、AI 与备课

> 使用 AI 功能前，需由学校管理员在后端配置 AI 服务商和模型密钥。未配置时页面会提示且不会崩溃。

### 10.1 AI 对话

教师专属 AI 教学助手。操作步骤：
1. 进入 AI 对话页面，在底部输入框输入问题或指令。
2. 支持自然语言提问：备课咨询、教案思路、成绩分析建议、评语撰写等。
3. 支持多轮连续对话，上下文保持。
4. 左侧边栏可查看和管理历史会话（新建、切换、置顶、删除）。
5. 会话数据持久保存，跨设备登录后仍可查看。

### 10.2 教案生成

**优质教案生成**：
1. 进入「优质教案生成」页面。
2. 填写年级、科目、教材版本、学期、课题。
3. 点击「生成」，AI 自动输出结构化教案（教学目标、重难点、教学过程、板书设计、课后作业等）。
4. 生成后可编辑完善，一键保存到教案库。

**教案库管理**：
查看、编辑、删除已生成的教案，按科目和年级筛选。

**教案模板**：
管理教案模板，支持新建/编辑/删除，生成教案时可选用模板作为框架。

### 10.3 知识点生成

1. 进入「知识点生成」页面。
2. 填写年级、科目、教材、学期、知识点主题。
3. AI 生成结构化讲解：定义、重难点、易错点、典型例题、复习建议等。
4. 可存入知识点库。

**知识点库**：管理已生成的知识点，支持增删改查。

### 10.4 试卷生成

**优选试卷生成**：
1. 进入「优选试卷生成」页面。

3. AI 生成贴近真实考纲的试卷（题目 + 答案 + 详细解析，模拟题明确标注）。
4. 生成后可存入选卷库。

**试卷库**：管理已生成的试卷，支持检索和筛选。

**试卷查询**：按条件查找试卷资源。

### 10.5 教材知识库

查看学校统一维护的教材知识点体系。教师可浏览各年级、各科目的教材知识结构，辅助备课。内容由学校管理员在后台统一管理。

### 10.6 专项资源库

浏览学校统一的专项教学资源（视频、音频、文档、图片等）。教师可在线查看和使用资源，辅助课堂教学。内容由学校管理员统一维护。

### 10.7 AI 文生图

输入文字描述，AI 自动生成教学配图，用于课件制作、班级装饰、活动海报等场景。

## 十六、常见问题（FAQ）

**Q1：为什么我看不到某些功能模块？**

A：系统的功能模块由学校管理员通过「功能包开关」控制。若某个菜单不可见，说明该功能模块未对您的学校开放。请联系学校管理员确认功能包授权。

**Q2：成绩录入时提示「该考试未设置科目」怎么办？**

A：请先在「考试管理」中编辑该考试，勾选所有需要录入成绩的科目并保存。科目设置后，成绩管理中的科目下拉框会自动同步。

**Q3：考勤保存失败是什么原因？**

A：常见原因包括：(1) 未选择班级；(2) 班级暂无学生；(3) 网络连接异常。请检查班级是否已分配学生，确认网络正常后重试。

**Q4：AI 对话没有回复或提示未配置？**

A：AI 功能需要学校管理员在后端配置 AI 服务商和模型密钥。如未配置，所有 AI 功能（对话、生成教案、知识点、试卷等）均不可用。请联系管理员。

**Q5：批量导入学生失败怎么办？**

A：请检查 CSV 文件格式：(1) 确保列序为「姓名,性别,学号,家长姓名,家长电话」；(2) 姓名列为必填；(3) 学号和家长电话不能与已有学生重复；(4) 建议先下载模板，按模板格式填写。导入对话框会显示具体错误信息。

**Q6：家长端开通后家长如何登录？**

A：开通家长端后系统会显示默认密码。请将默认密码告知家长，家长使用微信小程序或 Web 家长端登录，登录后建议立即修改密码。教师可在学生管理中对已开通家长端的学生重置密码。

**Q7：删除学生会影响已有数据吗？**

A：删除学生时系统会提示「此操作会同时清理该学生的相关数据，不可恢复」。该学生的成绩、考勤、行为记录、奖励记录、成长记录等关联数据会被同时清理。请谨慎操作。

**Q8：我换了一台电脑登录，数据还在吗？**

A：所有班级、学生、成绩等教学数据均存储在云端数据库内，换设备登录同一账号数据自动同步，不会丢失。

**Q9：工作台的考试均分趋势为什么是空的？**

A：考试均分趋势需要至少录入一次考试成绩后才会显示。请先在「考试管理」创建考试，再在「成绩管理」录入各科成绩，系统会自动聚合生成趋势图表。

**Q10：如何设置课程和科目？**

A：如果您是班主任，进入「班级成员」页面，选择班级后下拉到「本学期课程设置」区域，从科目库中勾选本学期课程，为每门课填写任课老师姓名后保存。如果您不是班主任，请联系该班班主任设置。

## 1. 登录系统

1. 打开系统地址，进入登录页
2. 输入校管用户名和密码（由超管创建）
3. 点击「开始工作 →」
4. 校管只能看到所属学校的数据

## 3. 人员管理

### 3.1 教师管理
- **搜索**：支持按姓名/账号/手机搜索
- **导出**：支持 CSV / XLS 格式导出教师列表
- **新增**：填写姓名/手机/性别/学科/职务 → 系统自动生成教师编号
- **批量导入**：下载模板 → 填写教师信息 → 上传文件批量导入
- **详情**：查看联系方式、任教学科、任课班级
- **编辑**：修改教师基本信息
- **功能权限**：配置该教师可用的功能模块
- **重置密码**：输入新密码重置教师登录密码
- **删除**：删除教师账户（不可恢复）

### 3.2 班级管理
- **新增班级**：选择年级 → 填写班级名 → 保存
- **编辑班级**：修改班级信息
- **年级晋升**：将班级提升到下一个年级
- **班级详情**：查看班级学生和科任老师

### 3.3 学生管理
- **搜索**：按姓名/学号搜索
- **班级筛选**：按班级过滤学生
- **新增/编辑/删除**学生
- **开通家长端**：为学生开通家长登录（家长可用学号+密码登录查看孩子信息）
- **重置密码**：重置家长登录密码
- **关闭家长端**：关闭家长登录权限
- **批量导入**：下载模板填写上传

## 11. 常见问题

**Q1：校管可以管理多所学校吗？**
A：每个校管只能管理一所学校。如需管理多所学校，请联系超管创建多个校管账户。

**Q2：批量导入教师/学生失败怎么办？**
A：请检查文件格式是否与模板一致，必填字段（姓名/学号）是否填写完整。

**Q3：如何查看教师的登录状态？**
A：在教师列表中查看"状态"列，绿色"启用"表示可登录，灰色"停用"表示已禁用。

**Q4：家长开通后能看到什么？**
A：家长可以看到自己孩子的成绩、作业、考勤、班级公告、教师留言等信息。

**Q5：删除班级后学生会怎样？**
A：删除班级会同时删除该班级所有学生和成绩数据，操作不可恢复。

**Q6：学科组长如何配置？**
A：学校管理员可配置年级各学科组长，学科组长可编辑所负责学科+年级的教材知识库内容，确保教材内容审核由学校端控制。

## 二、缺陷清单

### 缺陷 #1（严重）：config.vue 缺少 flushTabBarStyle 导入

- **编号：** TC-FE-FUNC-001
- **严重等级：** P1 - 功能缺陷
- **位置：** `mini-program/src/pages/config/config.vue` 第 296 行
- **现象：** 设置页 `onShow` 调用 `flushTabBarStyle()` 但该函数未在 import 语句中引入
- **影响：** 用户切换到"设置"Tab 时触发 ReferenceError，页面可能白屏或 tabBar 主题色不刷新
- **根因：** 第 113 行 import 语句仅导入了 `auth, setUser, logout, theme, setTheme, cycleColorScheme, SCHEMES`，遗漏了 `flushTabBarStyle`
- **对比：** 其余 4 个 Tab 页（dashboard/classes/students/toolbox）均正确导入了该函数
- **修复方案：** 在 import 语句中补充 `flushTabBarStyle`

### 缺陷 #2（低）：bcrypt 哈希耗时偏高

- **编号：** TC-PERF-003
- **严重等级：** P3 - 性能观察
- **现象：** bcrypt hash (cost=10) 在测试环境耗时 226ms，超过 200ms 基准
- **影响：** 生产环境（1CPU/2GB 云托管）首次登录可能感知轻微延迟
- **结论：** 属于测试环境资源限制，非代码缺陷。生产环境 bcrypt cost=10 在 200-300ms 为正常范围，无需修改

### 缺陷 #3（低）：成绩统计中位数计算精度

- **编号：** TC-BIZ-050
- **严重等级：** P3 - 边界条件
- **现象：** 偶数长度数组中位数取两中间值平均，浮点精度可能导致 .5 结尾
- **影响：** 前端展示可能出现 84.5 等非整数中位数
- **结论：** 属于正常数学行为，前端展示时保留一位小数即可，非缺陷

### 缺陷 #4（信息）：EmptyState 组件未在 dashboard 引用

- **编号：** TC-FE-FUNC-016
- **严重等级：** P4 - 测试用例偏差
- **现象：** dashboard.vue 使用内联空状态文本而非 EmptyState 组件
- **结论：** 非代码缺陷，dashboard 的空状态为简单文本提示（如"今天没有课程安排"），无需使用独立组件。EmptyState 在 classes/students/grades 等列表页正确使用
